# iki design agency

Independent UI/UX design and frontend web engineering studio. We build modern, high-performance websites, web applications, and digital platforms for companies, studios, and growing businesses.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Lucide React
- **Forms**: Web3Forms integration

## Interactive Demos Included
- **Jan's Hair Store**: Production flagship e-commerce digital storefront (`janshair.store`)
- **Estara Living**: Minimalist real estate & architectural living showcase (`/demos/estara/index.html`)
- **Apex Hoops**: Kinetic sports academy & training schedule landing page (`/demos/apex-hoops/index.html`)
- **Aura Dental**: Modern clinical web interface with online booking flow (`/demos/aura-dental/index.html`)
- **Mi Kafetal**: Artisanal coffee menu showcase with flavor-adaptive roast themes

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
